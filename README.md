# Vaz a Pose

Da câmera pra tela, já revelada. Criado por **Juan Vaz**.

## Baixar

**[Baixar o instalador da versão mais nova](../../releases/latest)**
(na página que abrir, clique no arquivo `Instalar-Vaz-a-Pose-….exe`).

## Instalar no Mac (Apple Silicon: M1, M2, M3, M4)

1. Na página da versão, baixe o `Vaz-a-Pose-Mac-….zip` e abra (ele vira o **Vaz a Pose**).
2. Arraste o **Vaz a Pose** pra pasta **Aplicativos**.
3. Na primeira vez, o Mac avisa que não pode verificar o app (ele ainda não tem a assinatura da Apple).
   Vá em **Ajustes do Sistema → Privacidade e Segurança**, role até o aviso do Vaz a Pose e clique em **Abrir Mesmo Assim**.
4. Se o Mac pedir pra permitir conexões de entrada, clique em **Permitir**: é a câmera pelo Wi-Fi e o celular.

Câmera no cabo no Mac: deixe o app **Fotos** e o **Captura de Imagem** fechados enquanto fotografa.

## Instalar no Windows

1. Abra o arquivo baixado (`Instalar-Vaz-a-Pose-….exe`).
2. **O Windows pode mostrar "O Windows protegeu o computador".** É esperado: o Vaz a Pose ainda não tem assinatura digital (um certificado pago), então o Windows não reconhece o autor.
   Clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Clique em **Instalar**. Não precisa ser administrador.
4. Pronto: o Vaz a Pose fica na Área de Trabalho e no Menu Iniciar.

### Se aparecer "Controle Inteligente de Aplicativos bloqueou…"
Essa proteção do Windows 11 não deixa abrir apps sem assinatura digital, e não tem botão de executar.
Se você quiser instalar mesmo assim, pode desligá-la:
**Segurança do Windows → Controle de aplicativos e navegador → Configurações do Controle Inteligente de Aplicativos → Desativado**.
Depois abra o instalador de novo: vai aparecer só o aviso de "Executar assim mesmo".

> Atenção: em algumas versões do Windows 11, depois de desligar não dá pra ligar de novo sem reinstalar o Windows (o próprio Windows avisa na hora). O antivírus continua funcionando normalmente. A decisão é sua; na dúvida, fale com o Juan.

## Atualizações

O app avisa sozinho quando sai versão nova (**Nova versão · Atualizar**, no topo).
Ao atualizar, ele fecha, instala e abre de novo. Se o Windows mostrar um aviso e o app não reabrir, é só abrir pelo atalho.
Seus perfis, presets e fotos nunca são apagados numa atualização.

## Desinstalar

Configurações do Windows → Aplicativos → **Vaz a Pose** → Desinstalar.
Os perfis (`AppData\Roaming\Vaz a Pose`) e as fotos (`Imagens\Vaz a Pose`) continuam no PC.
